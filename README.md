# 💎 FinDash Pro — Gestão Financeira Inteligente & Vendas

> **Aplicativo Web & PWA Mobile-First** para gestão de faturamento, controle de estoque (CMV), margens de lucro líquido e acompanhamento de metas mensais.

🌐 **Acesse Online 24 Horas:**  
👉 **[https://rennanlucas.github.io/findash-pro/](https://rennanlucas.github.io/findash-pro/)**

---

## 📱 Recursos Principais

* **100% Mobile-First:** Projetado sob medida para uso no celular com navegação pelo dedão no rodapé.
* **Design Sóbrio & Minimalista:** Paleta dark/slate fosca de fintech premium (Apple Wallet / Linear), sem excesso de cores chamativas.
* **Auditado ao Centavo:** 100% de precisão contábil com base no relatório original FinDash (44 transações, 32 vendas, R$ 70.440,00 faturados, R$ 11.456,00 de lucro líquido acumulado e R$ 2.311,00 em outubro/2026).
* **Filtros Reativos:** Filtro por mês (Outubro, Setembro, Agosto, Julho, Geral), filtro por tipo (Vendas vs Gastos) e busca instantânea em tempo real.
* **Categorias Abrangentes (+ Digitar Outra):** Suporte a produtos de tecnologia, periféricos, e gastos operacionais/pessoais, com botão para criar categorias personalizadas na hora.
* **Instalável (PWA):** Instale direto na tela inicial do celular como um app nativo com ícone oficial.
* **Modo Offline:** Funciona mesmo sem conexão com a internet através do Service Worker e do arquivo portátil único `findash-pro.html`.
